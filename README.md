# WhatsApp Backend MVP

A backend MVP inspired by WhatsApp group messaging, built using Flask and PostgreSQL.

## Features

- User registration and login
- JWT-based authentication
- Create groups
- View groups
- Add members to groups
- Remove members from groups
- Group-specific admin and user roles
- Send messages
- Read group messages
- Admin-only message deletion
- PostgreSQL database integration
- REST APIs for Postman testing

## Technologies Used

- Python
- Flask
- Flask-SQLAlchemy
- Flask-JWT-Extended
- PostgreSQL
- pgAdmin
- Postman
- Git & GitHub
